# night-landlord

> 末日生存题材 · 经营 + 轻塔防 + 放置 的中度小游戏。核心反转：**保住邻居不死，就能无限收租**。

## 项目命名体系

| 用途 | 名称 |
|---|---|
| 开发项目名（本仓库） | `night-landlord`（内部代号 Project RN / Rent & Night） |
| 中文产品主名 | 《永夜收租人》 |
| 出海产品名 | Night Landlord |
| 买量长副标 | 保住邻居，就能无限收租 |
| 灵感来源 | 短剧《永夜苟神：十万住户供我发育》（改编自起点小说《我在永夜打造庇护所》），未授权阶段与"苟神"IP 完全切割 |

## 技术路线（已定）

- **平台**：微信 + 抖音小游戏优先；H5 仅作落地页/playable ad 配套；原生 App 为 Phase 2
- **客户端**：Cocos Creator 3.x + TypeScript
- **服务端**：MVP 微信云开发（云函数 Node.js/TS）→ Phase 2 自建 Node/Go + MySQL/Redis
- **共享层**：数值公式 / 战斗判定 / 协议做成双端共享 TS 包（服务端复算防作弊）
- **美术**：AI 生成管线 + Spine 骨骼动画，对齐 AI 漫剧审美
