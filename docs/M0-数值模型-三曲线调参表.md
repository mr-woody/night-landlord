# M0 · 数值模型：产出 / 强度 / 付费三曲线调参表（v0.1）

> 前置文档：《永夜苟神》游戏完整设计方案（下称"设计方案"），本文档展开其 4.7 节数值框架。
> 口径：一切数值按 **F2P 中位数玩家** 基准计算（不充值、看广告、正常操作）；付费线单独对照。
> 状态：首版调参起点，不是真理。所有常量都有"建议区间"，M1 白盒版按第 11 节验收标准回填实测。

## 0. 这份文档怎么用

1. **M1 开发前**：第 2 节常量表就是未来 `CFG_*` 配置的初始值；第 5 节主表就是模拟器逐日校验的期望值。

## 1. 三曲线总览与主公式

```
产出曲线 I(d) ──投资──▶ 防御力 F(d) ──对抗──▶ 强度曲线 T(d)
     ▲                    │                      │
     │                    └── 失守 → 住户死亡 → 收入线断裂（负反馈）
     └── 收租 → 再投资 → 更多存活住户（复利飞轮）

付费曲线 = 在 F(d) 追不上 T(d) 的"跳变日"（血月），出售 战力/资源/永久加成
```

| 符号 | 含义 | 单位 |
|---|---|---|
| `d` | 游戏内天数（1 天 = 现实约 4 分钟） | 天 |
| `P(d)` | 存活住户数（主角不计） | 人 |
| `q(d)` | 品质结构系数（N/R/SR/SSR 加权，N=1.0、R=1.5、SR=2.5、SSR=5.0） | 系数 |
| `u(d)` | 户均升级系数（住户/岗位升级） | 系数 |
| `M(d)` | 全局乘数（天赋/月卡/公约 debuff；F2P 基准 = 1.0） | 系数 |
| `I(d)` | 日租金收入（硬通货金币） | 金币/天 |
| `hp(d)` | 单怪基准 HP | HP |
| `W(d)` | 当晚进攻路数（被攻击房间数） | 路 |
| `T(d)` | 夜晚总威胁 = `W×hp`（近似：全部进攻怪 HP 合计） | HP |
| `F(d)` | 防御力需求目标（守卫+武器+工事的合成战力） | 点 |
| `r(d)` | 防线比值 = `F/T`，**本模型的胜负与情绪主轴** | 比值 |
| `β*` | 防御投资占产出比例（按"血月周期"统计，非单日） | % |

**主公式组：**

```
① 产出：I(d) = P(d) × R0 × q(d) × u(d) × M(d)          ，目标包络 I(d) ≈ I(1) × 1.12^(d-1)
② 人口：P(d) ≤ min(食堂容量(d), 已建房间(d))             （食堂 = 第一个软卡点）
③ 升级：u(d) = 1.055^(d-1)                              （升级线成本另按 1.18/级 递增，多线并行）
④ 强度：hp(d) = HP0 × 1.15^(d-1) × J(d)                ，J = 1.6 当 d ∈ {7,14,21,28}（血月），否则 1
⑤ 路数：W(d) = min(1 + ⌊d/4⌋, 5) + (血月 +1)            ，上限 6 路
⑥ 防线：r(d) = F(d) / T(d)                              ，r 的逐日目标见第 5 节主表
⑦ 战力成本：1 点战力 ≈ 2.6 金币（武器/工事/守卫培训综合转化价 K）
⑧ 失守代价：按 r 落入的死亡带扣减住户（见 4.3），死亡 = 永久断该户收入线
```

## 3. 产出曲线

### 3.1 分解逻辑

产出增长 1.12/天 由三个部件相乘凑出：

| 部件 | D1 → D30 | 日均贡献 |
|---|---|---|
| 人口 `P` | 10 → 30（3.0×） | ≈ +3.9%/天（受食堂/房间双上限，阶梯式） |
| 品质结构 `q` | 1.00 → 1.68（1.68×） | ≈ +1.8%/天（招募结构上移 + 卡池 SSR 落地） |
| 户均升级 `u` | 1.00 → 4.72（4.72×） | ≈ +5.5%/天（升级线 1.18/级 成本递增，玩家多线追） |

### 3.2 校验

- `I(1) = 10 × 100 × 1.00 × 1.00 = 1,000 金币/天` → 覆盖 2 项基础升级（门 Lv2 = 500/项）✓ 对齐锚点"D1 日租金覆盖 2 项基础升级"。
- 实测日均环比 **1.118**（目标 1.12）✓；`I(30)/I(1) = 23.8×`（目标 26.7×，−11% 在容差内；要补齐把 `G_U` 1.055→1.06）。
- D1→D2 环比 1.53× 为**导演式跳涨**（广播站批量招募，对齐新手表 D2"人口跳涨、收入跳涨"），非失控。

### 3.3 支出预算线（产出去哪儿）

| 去向 | 占比 | 说明 |
|---|---|---|
| 防御投资（战力） | 17% → 58%，逐周期上升 | 见第 6 节 squeeze 量化，本模型的核心张力 |
| 人口（招募/食堂/引荐） | ≈15% | "贪人口 vs 先升级食堂"的取舍来源 |
| 发展（房间扩建/住户升级） | ≈30% | 复利飞轮的燃料 |
| 战斗消耗（弹药/耐久/医疗） | ≈8% | 夜战的持续成本，防"无脑堆防御" |
| 仓储缓冲 | ≈10% | 仓库扩容卡点的购买力来源 |

## 4. 强度曲线

### 4.1 对原方案公式的修正（重要）

设计方案 4.5 的 `HP = base × (1 + 0.18×天数)^1.35` 是**多项式增长，日环比随天数衰减**（D1 夜 +33%/天 → D20 后 +9%/天 → D30 后 <8%/天），后半程压不住 1.12 的产出曲线，与 4.7 节"强度指数≈1.15/天"直接矛盾。本模型改为：

```
hp(d) = HP0 × 1.15^(d-1) × J(d)      （恒定日环比 1.15，跳变交给血月 J 承载）
```

"怪物进化树"（循声者→破窗者→攀楼种→飞行种→围攻AI→精英种→夜王）保持为**内容层**：新变种 = 新怪图鉴 + 新机制（翻窗/飞行/集火），以 `W` 路数和机制复杂度体现，不再堆指数。

### 4.2 跳变日修正

原方案"第 7/14/21/**30** 天跳变"与自身"周期级 7 天血月"矛盾。改为 **7/14/21/28**（严格 7 天章节节奏），D30 = 第一栋满层 + 夜王预告（对齐 4.7 锚点与新手表 D14/D30 安排），不设跳变，给玩家进入第二栋前的喘息期。

### 4.3 失守死亡带（r → 当夜损失）

| r 落点 | 结果 | 设计意图 |
|---|---|---|
| ≥ 1.20 | 全守住，无伤 | 安全感（苟） |
| 1.05 – 1.20 | 守住，1–2 人轻伤（医疗费） | 疼而不死 |
| 0.95 – 1.05 | 惨胜：**死 1 人** + 恐慌上升 | "勉强能过"的代价，血月基准体验 |
| 0.80 – 0.95 | 死 2 人 + 破防房间恐慌 | 补强信号 |
| < 0.80 | 死 3 人以上 | 螺旋预警（连续两夜 → 流失风险） |

护栏：单夜死亡 ≤ 4，前 30 天累计死亡 ≤ 6（≈20% 人口，引荐/招募可回补）——对应"疼但不死"原则与假设 H3 的灰度中档。本模型 F2P 基准 30 天累计死 **5** 人（D7/14/21/27/28），在护栏内。

## 6. 防御预算 squeeze（三曲线咬合的量化证明）

防御投资按"血月周期"结算（`ΔF × K ÷ ΣI`）：

| 周期 | ΣI 产出 | 战力需求增量 ΔF | 防御投资 | **占产出比 β*** |
|---|---|---|---|---|
| D1–7 | 15,350 | 997 | 2,592 | **17%** |
| D8–14 | 36,518 | 3,790 | 9,854 | **27%** |
| D15–21 | 68,569 | 11,104 | 28,870 | **42%** |
| D22–28 | 116,274 | 25,768 | 67,000 | **58%** |
| D29–30 | 46,184 | 需求回落 | ≈0 | **0%（喘息）** |

这就是"强度 1.15 压产出 1.12"的复利效果：**防御预算占比每个血月周期 ×约1.6**，玩家的可自由支配收入被逐步挤干——到 D22–28，不借助流派 build（铁壁流减伤 30% ≈ 等效战力 +43%）、广告空投或付费，F2P 将无钱发展。付费曲线的所有时点都压在 squeeze 拐点上。

## 9. 对设计方案的三处修正记录

1. **强度公式**（4.5）：`(1+0.18d)^1.35` 日环比随天数衰减（D20 后 <1.09/天），压不住 1.12 的产出，与 4.7"1.15/天"矛盾 → 改 `HP0 × 1.15^(d-1) × J`，进化树转内容层。
