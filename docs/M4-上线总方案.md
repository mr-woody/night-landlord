## 3. 方案选型（决策 K5–K8）

### K5 存档产品化
| 选项 | 评估 |
|---|---|
| A. headless CLI 槽位存档（save/load/list + 哈希校验 + 迁移） | ✅ 采纳：复用 persistence 单点，CI 可测，微信端同构迁移 |
| B. 仅内存检查点 | 不可运营（掉线即丢） |
→ **K5=A**；微信端 M4 将 persistence 换 wx.setStorageSync 适配插件（宿主差异=Bundle 组合，FR-G1）。

### K6 包体积策略
| 选项 | 评估 |
|---|---|
| A. 引擎全量进主包 | 7.4MB 超 4MB 红线，❌ |
| B. **引擎引擎模块按需 + cocos-js 走分包/CDN**，逻辑包（assets/main+src）独立门 ≤1MB | ✅ 采纳：微信支持引擎分包；CI 门先锁逻辑包 |
| C. 裁剪引擎模块（去 3D/物理/spine） | ✅ 并入 B：构建配置 includeModules 收敛（当前含 3d/physics/spine 等，白盒只需 2d+ui+graphics+tween） |

→ **K6=B+C**：E2 先立「逻辑包 ≤1MB」CI 门与裁剪清单，分包落地在正式构建时核销。

### K7 天气/耐久接入夜战数值（ADR-17 预备）
- 方案 A：直接乘入威胁（破坏 M0 锚点窗口）❌；方案 B：**锚点窗口（D1–30）系数=1，D31+ 生效**（day_curve 之外区域），ADR 记录公式与回归门（V13 扩展）→ 采纳 B，ADR-17 草案交用户批准。

### K8 未成年/隐私
- 页面骨架+合规文案位先行（E4 附带），实名/防夫妻档依赖平台能力，M4 联调。

## 5. 技术架构增补

- **存档**：`apps/headless/src/main.ts` 增 `save/load/list` 子命令；槽位文件 `saves/<slot>.json`（GameState + WorldState + meta{day,seed,hash,version}）；载入走 `deserializeWorld` 迁移 + `checkInvariants` 断言。
- **体积门**：`scripts/check-size.mjs`——白盒 bundle ≤800KB（当前 ~500KB）；Creator 构建存在时：assets/main+src+game.js ≤1MB，并输出分包建议（cocos-js→微信分包/CDN）。
- **远程配置契约**：`@rn/control` 增 `OverlaySource { load(): Promise<OverlayFile> }`；本地文件源 `FileOverlaySource`；远程 HTTP 源留接口（M3 远程开通时实现，校验逻辑复用 applyOverlay 单点）。
- **分层不变**：新增代码全部落插件/纯函数包，零循环依赖（depgraph CI 守护）。
