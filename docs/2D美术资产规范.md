# 2D 美术与音画资产规范：全资产建模规格（v2.0 全量版）

> 回答两个问题：① 全案锁定 **2D**（竖屏剖面、Flat shading、无透视、无 3D 建模）——"建模"指**立绘/贴图/骨骼绑定/动画状态机/UI 皮肤/音画**的资产规格；② 结合全部需求与功能文档清点出的**所有**可视/可听资产类别，逐类给出规格。
> 事实源：设计方案 §4–§8、架构需求文档 FR/NFR、内核档 §5、M0 数值档、M2 台账、UI-UX设计规范（界面层）。
> 本档 v2.0 取代 v1.0（新增：UI 控件皮肤/天赋卡面/技能战斗演出/音频/字体/剧情运营素材/房间皮肤主题/全资产覆盖矩阵）。

---

## 一、总风格定调（全资产强制，含音频）

| 项 | 定值 |
|---|---|
| 渲染 | 2D 正交剖面，无透视；Flat shading + 粗深色描边（#0B1020 系）；光源统一左上 45° |
| 色板 | theme.json 色板（bg_night 深蓝底 / alert_blood 血红 / gold_primary 金）——双相叙事：白天暖金 ↔ 夜晚冷蓝血红 |
| 帧率 | 骨骼动画实时（Spine）；序列帧仅特效；逻辑 15Hz 战斗帧不受影响 |
| 音频基调 | 夜晚低频压迫音（BGM）+ 天亮收租清脆金币声（条件反射锚点，设计方案 §八）——夜晚压抑/白天释放的双相音频叙事与视觉同构 |
| 导出 | 视觉 @2x PNG 透明底 + TexturePacker 图集；音频 m4a(AAC)/ogg 双格式，响度 -16 LUFS |

**视觉/听觉分层**：环境背景层 → 建筑层 → 物品层 → 角色层 → 特效层 → UI 层；音频层：BGM 层（昼夜切换）→ 环境 AMB 层（风/雨/怪嚎）→ SFX 反馈层 → UI 音层。

**视觉 z 序**：环境背景层 → 建筑层（房间/公共建筑）→ 物品层 → 角色层（住户/怪物）→ 特效层 → UI 层。

## 二、人物（住户/主角/关键角色）

### 2.1 规格

| 项 | 定值 |
|---|---|
| 全身立绘 | 1024×1024 @2x（正面，剖面朝向即侧身 3/4） |
| 半身立绘 | 750×750（事件卡/对话用） |
| 头像 | 圆形 96×96（事件卡/住户详情） |
| 骨骼 | Spine：头/躯干/双臂×2/双腿×2 共 7 组基础骨骼 + 表情滑条 |
| 动作集 | idle（呼吸循环 2s）/ 走 / 睡 / 惊 / 战斗（守卫）/ 工作（职业动）——6 基础 |

### 2.2 职业与品质视觉差

- **职业**（设计方案 §4.2）：厨师（白帽+锅）/ 工程师（工具腰带）/ 护士（红十字）/ 猎人（弓弩）/ 守卫（红臂章+棍）/ 理财（金丝眼镜）——同一基础人形换装+道具。
- **品质色阶**：N 灰衣 / R 蓝边框 / SR 紫饰 / SSR 金框+入场特效底——对齐 M0 §4.2 品色阶。
- **关键角色**：江莱（SSR·理财·金色系）、林鹿溪（SSR·战斗·血红系）——首例外加专属入场动画。

### 2.3 状态机

| 状态 | 视觉 | 触发 |
|---|---|---|
| 健康 | 正常贴图 | 默认 |
| 受伤 | hp<100：绷带贴图叠加 | 夜战 WOUND |
| 恐慌 | panic≥70：抖动参数 + 冷汗贴图 | 事件/破防传播 |
| 死亡 | 灰化 + 倒地帧（序列帧 3 帧） | KILL（夜战/剧情，事件禁用） |
| 出逃 | 门位离场帧 | panic≥70 掷骰 |

### 3.3 房间装修皮肤主题（M4 商业化外观，设计方案 §5.2）

## 四、怪物（进化树，设计方案 §4.5）

### 4.1 规格与分级

| 层级 | 尺寸 @2x | 成员 | 动作 |
|---|---|---|---|
| minion | 192×192 | 循声者/破窗者/攀楼种 | 侧视行走循环（6 骨骼）+ 攻击×2 |
| elite | 256×256 | 飞行种/围攻AI/精英种 | 同上 + 特性动作（飞行悬浮/集火标记） |
| boss | 512×512 | 夜王 | 登场专用动画（M3） |

### 4.2 机制视觉（usableNightMods 对齐 monster.json）

- SILENT 夜怪物：半透明 70% + 红眼发光
- MIGRATE：移动时拖影（残影 2 帧）
- 破窗者/攀楼种：对应破门/翻窗攻击帧
- 死亡：崩解粒子（非帧动画，特效层承担）

### 4.3 怪物图鉴头像（M3，ord_205 研究尸体入口）

128×128 正面头像 + 剪影版（未解锁）+ 弱点标注贴纸位；按进化树排列。

| 类 | 清单 | 规格 |

| BGM | 白天（低保真暖旋律，循环 60–90s）/ 夜晚（低频压迫，循环 90s）/ 血月变奏（夜晚+打击乐层） | m4a+ogg，-16 LUFS，循环标记 |

## 十五、AI 生成管线（视觉类通用；音频不走 AI，走采购+委托）

统一后缀（所有视觉类别通用）：`末日生存卡通风格, flat shading, 粗深色描边, 高饱和点缀, 暗蓝底金色高光, 左上光源, 透明背景, 竖版手游素材`
负向：`写实, 3D, 透视, 渐变背景, 文字, 水印, 多光源`

| 类别 | 专属关键词段 |
|---|---|
| 人物 | `正面立绘, 半身, 职业服装:<职业>, 表情坚毅` |
| 怪物 | `剪影可读, 非人剪影, 尖爪利齿, 发光眼睛` |
| 房间 | `等距剖面, 家具陈设, 生活痕迹` |
| 物品图标 | `居中单体, 圆形底托, 高识别度` |
| 环境 | `整栋剖面, 七层结构, 废弃都市背景` |
| UI 皮肤 | `游戏UI九宫格, 扁平, 描边按钮, 无文字` |

流程四段：生成 8 候选 → 人工挑 1 → 清理（抠底/统一光源）→ 校验清单 → 图集集成。一致性策略：锚点图参考先行；风格稳定后可训练 LoRA 固化（M3 再评估投入）。音频：采购商用素材库（Epidemic/爱给网）+ 委托定制收租金币声三段（唯一需定制的核心锚点音）。

## 十六、资产校验清单（每次入库必过，视觉/音频分列）
