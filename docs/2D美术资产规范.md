# 2D 美术资产规范：人物/房间/怪物/物品/环境（v1.0）

> 回答两个问题：① 全案是 **2D**（竖屏剖面、Flat shading、无透视、无 3D 建模）——"建模"在此指**立绘/贴图/骨骼绑定/动画状态机**的资产规格；② 五类资产（人物/房间/怪物/物品/环境）各自的尺寸、状态、动画、AI 生成模板与命名。
> 上游合同：docs/UI-UX设计规范.md（tokens/动效曲线）、docs/M0-事件文案库（语调）、docs/技术架构与模块规划（Spine 选型）。

---

## 一、总风格定调（全资产强制）

| 项 | 定值 | 说明 |
|---|---|---|
| 渲染 | 2D 正交剖面，无透视 | 辐射避难所式竖屏剖面（设计方案 §一.8） |
| 上色 | Flat shading + 粗深色描边（#0B1020 系） | 对齐 AI 漫剧审美（设计方案 §八） |
| 光源 | 统一左上 45° | 所有资产一致，禁止多光源 |
| 色板 | theme.json 色板 + 每类情绪色 | 夜晚冷蓝底/血红警示/金色高光（双相叙事） |
| 帧率 | 骨骼动画实时渲染（Spine）；序列帧仅特效 | 逻辑 15Hz 战斗帧不受影响 |
| 导出 | @2x PNG（透明底）+ TexturePacker 图集 | 主包 ≤4MB 约束（超包走 CDN） |

**视觉分层**（z 序）：环境背景层 → 建筑层（房间/公共建筑）→ 物品层 → 角色层（住户/怪物）→ 特效层 → UI 层。

## 二、人物（住户/主角/关键角色）

### 2.1 规格

| 项 | 定值 |
|---|---|
| 全身立绘 | 1024×1024 @2x（正面，剖面朝向即侧身 3/4） |
| 半身立绘 | 750×750（事件卡/对话用） |
| 头像 | 圆形 96×96（事件卡/住户详情） |
| 骨骼 | Spine：头/躯干/双臂×2/双腿×2 共 7 组基础骨骼 + 表情滑条 |
| 动作集 | idle（呼吸循环 2s）/ 走 / 睡 / 惊 / 战斗（守卫）/ 工作（职业动）——6 基础 |

### 2.2 职业与品质视觉差

- **职业**（设计方案 §4.2）：厨师（白帽+锅）/ 工程师（工具腰带）/ 护士（红十字）/ 猎人（弓弩）/ 守卫（红臂章+棍）/ 理财（金丝眼镜）——同一基础人形换装+道具。
- **品质色阶**：N 灰衣 / R 蓝边框 / SR 紫饰 / SSR 金框+入场特效底——对齐 M0 §4.2 品色阶。
- **关键角色**：江莱（SSR·理财·金色系）、林鹿溪（SSR·战斗·血红系）——首例外加专属入场动画。

### 2.3 状态机

| 状态 | 视觉 | 触发 |
|---|---|---|
| 健康 | 正常贴图 | 默认 |
| 受伤 | hp<100：绷带贴图叠加 | 夜战 WOUND |
| 恐慌 | panic≥70：抖动参数 + 冷汗贴图 | 事件/破防传播 |
| 死亡 | 灰化 + 倒地帧（序列帧 3 帧） | KILL（夜战/剧情，事件禁用） |
| 出逃 | 门位离场帧 | panic≥70 掷骰 |

## 三、房间（剖面格子/公共建筑）

### 3.1 住户房间

| 项 | 定值 |
|---|---|
| 格子 | 320×192 @2x（逻辑 160×96，6F×5 房间网格） |
| 构图 | 门右、窗左（窗=环境剪影视口），家具 2–3 件按职业 |
| 状态 | 正常 / 破防（木板裂+血红涂鸦+玻璃碎）/ 升级（+1 家具/等级，3 级封顶） |

### 3.2 公共建筑（设计方案 §4.1 八件套）

大厅/医务室/仓库/食堂/工坊/广播站/议事厅/瞭望塔——每座 3 级外观贴图（lv1 基础 / lv2+构件 / lv3 全装），剖面朝左，占 2 房间宽。瞭望塔额外含"情报范围"光圈动效。

## 四、怪物（进化树，设计方案 §4.5）

### 4.1 规格与分级

| 层级 | 尺寸 @2x | 成员 | 动作 |
|---|---|---|---|
| minion | 192×192 | 循声者/破窗者/攀楼种 | 侧视行走循环（6 骨骼）+ 攻击×2 |
| elite | 256×256 | 飞行种/围攻AI/精英种 | 同上 + 特性动作（飞行悬浮/集火标记） |
| boss | 512×512 | 夜王 | 登场专用动画（M3） |

### 4.2 机制视觉（usableNightMods 对齐 monster.json）

- SILENT 夜怪物：半透明 70% + 红眼发光
- MIGRATE：移动时拖影（残影 2 帧）
- 破窗者/攀楼种：对应破门/翻窗攻击帧
- 死亡：崩解粒子（非帧动画，特效层承担）

## 八、AI 生成管线（分类 Prompt 模板）

统一后缀（所有类别通用）：`末日生存卡通风格, flat shading, 粗深色描边, 高饱和点缀, 暗蓝底金色高光, 左上光源, 透明背景, 竖版手游素材`
负向：`写实, 3D, 透视, 渐变背景, 文字, 水印, 多光源`

| 类别 | 专属关键词段 |
|---|---|
| 人物 | `正面立绘, 半身, 职业服装:<职业>, 表情坚毅` |
| 怪物 | `剪影可读, 非人剪影, 尖爪利齿, 发光眼睛` |
| 房间 | `等距剖面, 家具陈设, 生活痕迹` |
| 物品图标 | `居中单体, 圆形底托, 高识别度` |
| 环境 | `整栋剖面, 七层结构, 废弃都市背景` |

流程四段（业界主流，检索已证）：生成 8 候选 → 人工挑 1 → 清理（抠底/统一光源）→ 校验清单（§九）→ 图集集成。一致性策略：锚点图参考先行，风格稳定后可训练 LoRA 固化（Layer.ai / SD LoRA 模式，M3 再评估投入）。

## 九、资产校验清单（每次入库必过）

1. 主色全部落在 theme.json 色板 ±10% 内
2. 72px 缩放下剪影可读（怪物/图标必测）
3. 描边粗细与锚点图一致（±10%）
4. 透明底、无 AI 文字乱码、无多余肢体
5. 命名合规：`{模块}_{对象}_{状态}@2x`（如 `char_guard_walk@2x.png`、`room_bedroom_breach@2x.png`）
6. 骨骼动画：Spine 导出 JSON+图集，动作集齐全，循环动画首尾帧匹配
