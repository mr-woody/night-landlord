## 二、按依赖顺序的功能点

每点先跑变更范围 Unit-test（渲染数据函数），再跑该点所需的检查（esbuild 构建 + tokens 扫描 + 浏览器/DevTools 冒烟），通过后独立提交并记录哈希：

1. **theme.json 双端驱动落地**：白盒渲染器读 tokens 重绘（色板/字号/动效曲线全部改由 tokens 取）；新增 `scripts/check-theme.mjs` CI 扫描——bundle 内出现非 theme 色值 hex 即 FAIL；index.html 内联样式同步 tokens。
2. **主界面风格化**（对照 UI 规范 §3.1 线框 1:1）：顶部 HUD（日次/资源栏皮肤）+ 剖面楼栋立绘占位（6F×5 房间格子升级为带描边/家具占位/破防血红态）+ 底部 dock 四键（88px 热区）+ 事件卡入口样式；全部状态贴图占位（色块+图标剪影），不做终版美术。
3. **事件卡 + 夜战面板 + 收租结算风格化**：事件卡模板（标题栏/正文 24px/选项按钮/风险星级标识/结果翻转动效）；夜战面板（血月标记红闪、路血条三态、主动技 CD 环、战况日志）；收租结算（物资雨 rain 曲线 500ms + 计数器滚动 easeOutCubic 0.8s + 逐户弹出 60ms 间隔）；§二 motion 表五条曲线全部落地。
4. **图鉴/商店/设置占位页 + 合规扫描**：三页占位（图鉴 3 列网格剪影、商店礼包卡横滑、设置项列表）；热区 ≥88px、字号 ≥24 扫描脚本入 CI。
5. **AI 资产管线试跑**：按 2D 美术资产规范 §八 模板产出风格锚点 6 张 + 10 个 UI 素材（占位级）走完四段流程；锚点图入库 docs/assets/anchors/；校验清单全过。
6. **Creator 原生工程接入（用户安装 Creator 后）**：新建 2D 竖屏工程接入 sync 产物（ADR-9 方案 a），白盒渲染三屏移植到 Creator 场景；微信构建回归（验收门③复跑，cli open exit=0）。
7. **可用性自测清单 + 台账**：一天循环全相走查（打断/恢复规则验证）；docs/M2.5-证据台账.md 完整记录。
