## 4. FINDING（M2.5 发现，M3 输入）

- **FINDING-M2.5-1（事件卡 replay 语义）**：白盒事件卡是模拟回放——选项点击只驱动翻面动画，不改变已跑完的模拟（且 rollOutcome 现只掷 options[0]）。M3 实装交互事件时需把「选择→rollOutcome→applyEffects」接入运行时循环，§3.2 多选项才是真选择。
- **FINDING-M2.5-2（警戒带缺黄色 token）**：路血条三态的中档（0.95≤r<1）以 gold_deep 暗金承担，与「gold 只用于收租/货币」的色彩角色约束存在借用。建议 M3 在 theme.json 增补 `warn` 色 token 并同步修订 UI 规范 §二 色板表（走 ADR/文档修订）。
- **FINDING-M2.5-3（motion tokens 扩充）**：counter（800 easeOutCubic）/stagger（60ms）为落地 §3.4 而新增，§二 motion 表五条原样未动；追溯矩阵需登记该两枚 tokens 与 §3.4 的映射。
- **FINDING-M2.5-4（Creator 移植面）**：渲染层已拆为纯 TS（theme/layout/state/anim，无 DOM）+ 单文件 Canvas renderer，Creator 组件移植仅需替换 rAF/输入桥；P6 缓行期间未做引擎侧验证，接入时留意 roundRect 兼容性。
- **FINDING-M2.5-5（资产管线可换芯）**：管线 Stage1（候选来源）当前为确定性程序化生成；M3 换 AI 生成时仅替换该段，挑选/清理/校验/图集集成段直接复用（check-assets.mjs 即 §十六 清单的机器化实现）。
