# 《永夜收租人》UI/UX 设计规范与设计稿（v1.0）

> 适用范围：M2.5 UI 风格化实施 + 后续所有界面迭代。事实源：设计方案 §八（美术方向）、M2 白盒渲染器（布局原型）、M0 数值档（经济反馈节奏）。
> 统一驱动原则（对齐 v1.0 架构 D3 表驱动）：**所有视觉参数以 design tokens 定义（config/theme.json），禁止魔法数字**——Cocos 端、白盒渲染器、AI 资产生成 prompt 三处共用同一份 tokens。

> **游戏内美术资产（人物/房间/怪物/物品/环境）的 2D 建模规格、状态机与 AI 生成模板见姊妹文档《[2D美术资产规范](2D美术资产规范.md)》**——本文只管界面层。

## 一、设计原则（从项目文档推导，不可违背）

1. **双相色彩叙事**：白天暖（收租爽感·金色）↔ 夜晚冷（生存压迫·深蓝/血红）——色彩即游戏状态，切换必须有过渡动画（0.8s 交叉溶解）。
2. **AI 漫剧审美对齐**：Flat shading + 粗描边 + 高饱和点缀，对齐买量素材；禁止写实渲染。
3. **可读性优先**：小图 72px 内轮廓可读；正文字号 ≥24px（微信竖屏中端机）；热区 ≥88×88px。
4. **动效即反馈**：每一次点击 ≤0.1s 内必须有视觉响应；收租/升级等爽点动效 ≥0.5s 允许打断排队。
5. **Tokens 单一事实源**：色板/字号/动效曲线全部入 `config/theme.json`，与 M0 D3 表驱动哲学一致。

## 三、模块设计稿（竖屏 750×1624 逻辑分辨率）

### 3.1 主界面（白天·剖面楼栋）

```
┌─────────────────────────┐
│ [日次 D7] 🌙2/4  [⚙设置] │ ← 顶部 HUD：日次/进度/入口（48px 高）
│ 🪙12,345 👥24 ⚔1,132 🍖380│ ← 资源栏（图标+数字，金色数字动画）
│ ┌─────────────────────┐ │
│ │ 6F ▒▒▒▒▒ (瞭望塔)    │ │ ← 剖面楼栋：6F×5 房间格子
│ │ 5F [住][住][空]...   │ │   占用=亮格+角色立绘头像
│ │ ...   [守卫岗🔴]     │ │   破防房间=血红闪烁（threat 动效）
│ │ 1F [大厅][医务][仓]  │ │
│ └─────────────────────┘ │
│ [事件卡：深夜敲门人 ▶]    │ ← 今日事件入口（滑入，weight 高在前）
│ [布防] [招募] [升级] [▶夜]│ ← 底部 dock（4 键，88px 热区）
└─────────────────────────┘
```
- 交互流：点击房间 → 弹住户详情（升级/岗位/治疗）；点击 dock → 模态面板自底部滑入（normal 300ms）；「▶夜」→ 确认弹层 → 入夜转场（dissolve 800ms + 色板切 bg_night）。
- 连续性规则：任意模态可被事件卡打断排队（队列最多 2，先进后出恢复）；夜战不可被打断（全屏接管）。

### 3.2 事件卡（choice/mission 通用模板）

```
┌─────── 深夜敲门人 ───────┐  ← 标题栏（panel_stroke 描边）
│ 正文文案（≤2 行，24px）    │
│ ┌────────────────────┐  │
│ │▶ 开门   70%/30% ⚠   │  │  ← 选项按钮：风险星级标识
│ │  隔门询问        ✓  │  │
│ │  无视               │  │
│ └────────────────────┘  │
└─────────────────────────┘
```
- 动效：滑入 fast 150ms；选择后卡面翻转（normal）→ 结果文案浮现 → 效果图标飞向资源栏（rain 曲线 500ms）。
- 连续性：选择即锁定（不可回退）；结果入审计流（applyEffects 单点，FR-E5）。

### 3.3 夜战面板（NIGHT）

```
┌─────────────────────────┐
│ [血月 🔴] 第 3 波 ▶▶     │ ← 波次/特殊夜标记（SILENT=问号遮罩）
│ 路A ██████ 97% ⚠        │ ← 每路血条+战力比（红/黄/绿三态）
│ 路B ███░░░ 71% ⚠⚠       │
│ [空投物资💊] [护盾🛡]     │ ← 主动技（CD 环，热区 88px）
│      [ 战况日志滚动 ]     │
└─────────────────────────┘
```
- 动效：血月入场 threat 动效（红闪×2+震屏 0.3s）；路破防时整路血红脉冲；金币/伤员图标飞向资源栏。

### 3.4 收租结算（DAWN·标志性瞬间）

- 物资雨：金色方块从楼顶落下（rain 曲线 500ms，粒子 24 个）→ 落入金币计数器滚动（0.8s easeOutCubic 数字滚动）。
- 结算面板：存活住户逐户 +金币（每户 60ms 间隔弹出），总计数大字（h1 BebasNeue）。
- 收租×2 广告按钮：结算后常驻右下（不带强制弹窗，符合 IAA 合规）。

### 3.5 天赋三选一 / 商店 / 图鉴

- 天赋：三卡横排（竖屏横滑），稀有度边框色阶（N 灰/R 蓝/SR 紫/SSR 金），选中卡放大 1.1×（rain 曲线）；未选两张淡出。
- 商店/首充：礼包卡横滑，首充双倍角标（alert_blood）；价格锚点用删除线对比。
- 图鉴：网格 3 列，未解锁剪影 + 锁图标；点击翻牌预览（normal）。

## 四、交互流总图（一天循环 = UI 状态机）

```
DAWN_SETTLE: 结算面板(自动) → 物资雨 → 事件卡队列 → 存档提示
DAY:         主界面自由操作 ← 事件卡插播(≤2/日) ← 建筑详情模态
DUSK:        夜战预告横幅(SILENT 时替换为「?」) → 布防确认
NIGHT:       全屏夜战面板（唯一可交互面）→ 战况结算
→ 循环；任意相 fail-safe：掉线恢复到最近检查点面板（存档三检查点）
```

## 五、AI 资产管线（符合 M0 §八 AI 漫剧审美）

1. **风格锚点**：先人工确认 6 张锚点图（主楼剖面/住户头像×3 怪物×1/物资雨帧），所有后续生成必须附锚点图作参考（reference anchoring，业界一致性主流做法）。
2. **Prompt 模板**（统一后缀）：`末日生存卡通风格, flat shading, 粗深色描边, 高饱和点缀, 暗蓝底金色高光, 竖版手游 UI 素材, 干净背景 --ar 2:3`；角色加 `正面立绘, 半身`；怪物加 `剪影可读, 剪影测试 72px`。
3. **管线四段**：生成（8 候选）→ 挑选 1 → 清理（去背景/统一光源左上）→ 校验（色板合规/缩放测试/命名）→ 集成（SpriteSheet 打包）。
4. **命名**：`{模块}_{对象}_{状态}@2x`（如 `ui_btn_night@2x.png`）；图集用 TexturePacker。
5. **校验清单（每次资产入库必过）**：主色在 theme 色板内 / 72px 缩放可读 / 描边粗细一致 / 背景透明 / 无 AI 文字乱码。
