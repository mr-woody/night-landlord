# 战斗演出与天气系统设计（v1.0-draft→定稿，M3.2）

> 定位：本档定义①夜战类 3D 攻防演出（双方交互行为/技能效果/动画状态机）、②独栋房屋体系（房屋进化路径/间距属性）、③天气引擎（多维度环境参数与跨模块影响）。是战斗表现层、房屋渲染、weather 插件与其配置表的上位输入。
> 修订来源：2026-08-31 用户方向决议——夜战需实时战斗动画与场景、技能效果差异化、人物/物品/房屋差异化呈现；居住单元为独栋房屋（茅草屋→石屋进化，含间距）；天气引擎（气温/光线/湿度/光照对环境模块干扰）。
> 不变式：夜战**结算逻辑**（runNight，确定性、M0 契约）不变；演出为**表现层编排**（从 BattleSession 回放插值，不参与结算）——演出与结算分离，保 NFR-4 确定性与 V 门全绿。

## 1. 独栋房屋体系（居住单元重构）

### 1.1 决策 K-H1：居住单元独栋化
| 选项 | 评估 |
|---|---|
| A. 独栋小屋群落（每住户家庭一栋，可进化） | ✅ **采纳**：用户明确要求；房屋进化=养成深度的实体化；间距属性带来地图经营维度 |
| B. 保留 3 栋高层+楼内房间 | 与用户设定冲突 |
| C. 双轨（主楼+小屋区） | ✅ 融合采纳：主楼保留（玩家+公共功能核心，等距大体量），住户居住改为独栋小屋群落 |

→ **K-H1=A+C**：L2 小区地图重构为「主楼（核心堡垒）+ 独栋小屋群落 + 公共建筑带」。原 30 个防守单元（F1-Rn）语义映射为 30 栋小屋（小屋#1–#30），夜战路数模型/数值锚点不变。

### 1.2 房屋进化路径（6 级）

| 级 | 名称 | 外观要点 | 耐久系数 | 解锁 |
|---|---|---|---|---|
| 0 | 茅草屋 | 圆木骨架+茅草斜顶（枯黄）、泥地 | ×0.8 | 初始 |
| 1 | 破损木屋 | 木板墙（缺口/补丁）、破洞屋顶漏光 | ×0.9 | 建材 50 |
| 2 | 普通木屋 | 整齐木板、单坡屋顶、木门框 | ×1.0 | 建材 150 |
| 3 | 精品木屋 | 双色墙板、雕花门楣、气窗、石基 | ×1.15 | 建材 400+金 200 |
| 4 | 石屋 | 石块墙、石瓦顶、加固门框 | ×1.3 | 建材 800+金 500 |
| 5 | 砖石堡垒 | 砖石+瞭望角楼+铁门 | ×1.5 | M3.4 后赛季 |

- 进化消耗走 EffectOp（material/gold），耐久系数计入夜战该路 HP（进入 systems 需 ADR——本档先在 explore/world 侧以 `houseLevel` 记录，夜战加成 M3.4-② 接管）。
- **间距属性**：每小屋 `pos{x,y}` + `spacing`（与邻屋距离）；间距影响：房屋间距 ≥2 格时火灾/恐慌不蔓延（M3.4-② 实现蔓延预留），渲染上保证遮挡排序。

### 1.3 落位与渲染
- 小屋群落占 L2 南侧地块（主楼北侧），3 列×10 行错排（spacing=1.2 格）；
- 房屋渲染=程序化组合体（6 级各一个绘制函数，参数化屋顶/墙体/门/窗烟囱）；昼夜窗光、雨雪天屋顶湿润反光；
- 住户在场→烟囱冒烟（呼吸节奏）。

## 2. 战斗演出（类 3D 攻防，表现层）

### 2.1 分层契约（确定性红线）
```
逻辑层 runNight（不变，确定性结算 → BattleSession{routes,deaths,wounds,hash}）
        ↓ 回放（唯一数据源）
演出编排 battleDirector（表现层）：按 session.routes/ops 生成时间线
        → 实体动画状态机插值 → 渲染
```
- 演出不改结算结果；`battleDirector` 输出的时间线可由 session+seed 完全复现（可测试）。

### 2.2 战斗场景（类 3D）
- 场地：小区道路等距平面（斜 45°，带高度：围墙/小屋立面/瞭望塔），夜色+月光/血月光；
- 攻方：怪物按 route 波次从地图边缘行进至目标小屋（路径插值）；守方：守卫住户立于小屋前；
- 交互行为状态机（双方）：`spawn → advance → attack(cycle) → hitFlash(受击) → die(崩解粒子)`；住户：`guard → counterattack → wounded(倒地) → heal`。

### 2.3 技能效果（差异化演出）
| 技能 | 演出 |
|---|---|
| 空投物资 | 高空降落伞下落（摆动+减速）→落地光圈→物资箱弹开 |
| 护盾 | 全小屋蓝色半球罩 0.5s（描边呼吸）→期间受击弹开火花 |
| 主角技（冲击波） | 扇形冲击波扩散+地面裂纹 |
| 恐慌弱化 | 紫色雾环收缩 |
不同技能=不同粒子/轨迹/色板（全 tokens 派生）。

### 2.4 差异化呈现
| 实体 | 呈现 |
|---|---|
| 循声者 | 爬行姿+声波探测圈 |
| 破窗者 | 携梯/撞门动作 |
| 飞行种 | 悬浮+俯冲 |
| 精英种 | 体型 1.3×+红眼 |
| 住户（守卫） | 红臂章+武器类型差异（棍/弩） |
| 物品 | 掉落弹跳+光柱拾取 |

### 2.5 时间线规格
- 每波 3s：行进 1.2s → 交战 1.2s（攻击循环 0.4s×3，含 hitFlash/顿帧）→ 结果 0.6s（崩解/倒地）；
- 受击：白闪 2 帧+击退 4px+顿帧 2 帧（对齐美术规范 §十 命中反馈）；
- 演出总长 = 波数×3s，可 2× 速/跳过（放置原则：自动为主）。

## 3. 天气引擎（weather 插件 + weather.json）

### 3.1 天气类型（首版 6 种）

| 天气 | 光照 | 气温 | 湿度 | 环境呈现 | 模块影响 |
|---|---|---|---|---|---|
| 晴 | 暖金/月光清冷 | 常温 | 低 | 标准星空 | 基准 |
| 阴 | 灰蓝压暗 ×0.85 | 微降 | 中 | 云影移动 | 采集产出 ×0.9 |
| 雨 | 冷暗 ×0.75 | 降 | 高 | 雨丝粒子+地面反光+涟漪 | 采集 ×0.75；野物遭遇 ×1.2；守卫视野 −10%（夜战威胁 +5%） |
| 雾 | 灰白能见度低 | 降 | 饱和 | 雾层（远近三段） | 遭遇 ×1.5；瞭望塔情报降级（预告模糊） |
| 雪 | 冷白提亮 | 严寒 | 低(积雪) | 雪花粒子+积雪顶 | 采集 ×0.6；恐慌衰减 −20%；食物消耗 +10% |
| 血月尘暴 | 血红 ×0.6 | 燥热 | 极低 | 红尘粒子+风声 | 血月夜伴生：夜战威胁 +10%、探索禁用 |

### 3.2 天气序列（确定性）
- `weatherOfDay(day) = createDayRng(seed,'weather',day)` 抽取：基础概率表按天数段（D1–7 温和期/8+ 复杂期/血月日强制尘暴伴生）；
- 纯函数、可复算；天气进 DayRecord（`weather` 字段）与检查点。

### 3.3 跨模块影响接入点（全部走系数常量，进 weather.json）
| 受影响模块 | 接入方式 |
|---|---|
| explore（采集/遭遇） | resolveDue 乘 `weather.gatherMul/encounterMul` |
| 夜战（表现+轻度数值） | 表现层粒子/光照；数值侧 night 威胁 +5%/+10% 走 ADR（M3.4-② 评估，先表现后数值） |
| 渲染 | 粒子层（雨丝 120/雪花 80/尘 60）+ 全屏光照 overlay（multiply 色）+ 雾层三段 |
| 音频（M4） | 雨声/风声槽位预留 |
