## 2. 技术路线（K-V1 决策）

| 路线 | 评估 |
|---|---|
| **A. 部件化 2.5D 混合**：AI 生成等距视角 sprite（分层部件：本体/附件/眼爪发光件）+ 程序化骨骼变换动画（bob/lean/扑击=部件 rotate+translate，白盒既有手法）+ 粒子贴图 + 光效贴图 + 影子椭圆 | ✅ **采纳**：复用既有 battleDirector/状态机/粒子层（只换绘制源）；AI 生图管线直接产能；主包增量可控（@2x sprite + 图集）；确定性回放契约不破坏 |
| B. 实时 3D（Meshy/Tripo 产模 + Cocos 3D 等距相机） | 备选评估（P3 后）：真立体但包体/低端机性能/管线成本三重冲击，主包 4MB 红线下引擎 3D 模块+模型资产不可承受；与 AI 生图闭环不兼容 |
| C. 全 Spine 骨骼动画 | P3 评估项：表现力上限高，但 spine 运行时包体+部件拆分绘制成本大；A 路线的部件变换若不够再升 C（部件资产可复用） |

**路线 A 分层契约（继承 §2.1 确定性红线）**：资产=静态 sprite+部件图；动=程序化变换时间线
（battleDirector 派生，可由 session+seed 复现）；光=overlay/光效贴图乘算；粒子=tokens 派生参数。

## 3. 视角规格（资产层新增硬规范，全管线统一）

| 资产类 | 视角 | 关键词 |
|---|---|---|
| 主楼/小屋/公共建筑/天气场景 | **等距** | 等距 2.5D 视角，俯角约 30°，方位角 45°（左上前），统一消失点，带接地投影 |
| 怪物/住户（战斗实体） | **3/4 侧面** | 面朝右（行进方向→小屋在车道右端），带接地椭圆影 |
| 住户头像/图鉴立绘 | 正面半身 | 平视（既有不变） |
| 图标/UI/VFX 贴图 | 正视 | 居中单体 |
| 粒子贴图（烟/尘/光斑/火花） | 正视软边 | 允许渐变透明（豁免色板硬门，单列 particle 门） |

## 6. 迭代协议（本档执行方式）

`check:config` + `check:size`（P3 起）+ E2E → 台账留证 → 下一轮。冲突清单 §4 随轮滚动增补，
处置状态实时更新；全部门禁绿且用户终审通过后本档关闭、台账核销。
