## 一、全局视觉契约（每张场景资产强制，先读这一节再动笔）

| 项 | 定值 | 违反即打回 |
|---|---|---|
| 渲染基调 | 等距 2.5D 混合（CoC 立体感基准）：sprite 静态图 + 程序化部件动画，**非实时 3D、非纯平面贴图** | 出现真 3D 渲染感/纯正交平面感 |
| 场景视角 | 等距 2.5D：**俯角约 30°，方位角 45°（左上前），统一消失点，带接地投影**；同屏所有实体必须同视角 | 消失点不一致、缺投影 |
| 战斗实体视角 | 3/4 侧面，**面朝画面右**（行进方向），带接地椭圆影 | 朝向左/正脸 |
| 头像/图标视角 | 正视半身（头像）/ 正视居中单体（图标、VFX 贴图） | — |
| 光影 | 单一光源**左上 45°**；暗部/亮部 ≥2 防色阶；一切地面实体脚下椭圆影（透明度随高度衰减） | 多光源、逆光 |
| 描边 | 粗深色描边（`#0B1020` 系），线幅≈图形线幅 8%，等距资产统一 3px@1x | 描边缺失/过细 |
| 上色 | Flat shading，3–4 色块面，高饱和点缀 | 写实、复杂细节、渐变滥用 |
| 色板 | 主色必须落位 theme 12 基础色 ±10%（UI/白盒资产硬门）或扩展资产色板 43 色命中率 ≥85%（AI 资产门）；双相叙事：白天暖金 ↔ 夜晚冷蓝+血红 | 主色飘出 |
| 背景 | 透明底 PNG（`@2x`）；**全出血例外**：主楼剖面/天气氛围 6 张按整幅 key art 交付（不抠底，覆盖率 80–100%） | 四角不透明（非全出血类） |
| 分辨率基准 | 竖屏逻辑 750×1624，资产按 @2x 导出；TexturePacker 图集 | — |
| 可读性 | 怪物/图标 72px 缩放剪影可读（`char` 类必测）；场景类（`scene`）豁免 | 剪影糊成一团 |
| 命名 | `{模块}_{对象}_{状态}@2x.png`（如 `house_lv4_stone@2x.png`） | 命名不符 |
| 性能红线 | 同屏绘制调用 ≤60；逻辑 15Hz 不受表现层影响；主包 ≤4MB（当前 1360KB，素材增量 ≤800KB，sprite 走分包/CDN 预算线） | 超预算 |

**色板锚**（取自 `config/theme.json`，不要在提示词里写 hex——模型会画成色卡图例，色板由门禁+锚点参考图保障）：
深蓝底 `bg_night` / 血红警示 `alert_blood` / 金 `gold_primary`+`gold_deep` / 面板 `panel`+`panel_stroke` / 正文两阶灰 / 成功绿 / 危险红 / 恐慌紫。扩展资产色板见 `config/asset-palette.json`（31 族 43 色，含皮肤/发色/材质中间色）。

**统一提示词骨架**（现行管线版，见 `gen-ai-assets.mjs`）：

```
{主体描述}, {视角后缀·五选一}, 末日生存卡通风格, flat shading, 粗深色描边, 高饱和点缀,
左上光源, 纯色浅灰背景便于抠图, 手游素材, 3–4 色块面
负向：写实、3D 渲染、透视灭点、渐变背景、文字、水印、色卡、图例、标注、边框装饰、多光源、复杂细节
```

视角后缀五档：**iso**（等距场景）/ **side**（3/4 侧面朝右）/ **front**（正面半身）/ **icon**（正视单体）/ **flat**（正视全景）。

## 三、逐场景需求卡

### S1　L2 小区地图（默认主界面·家园层）

**镜头**：等距斜俯视，双指缩放+平移（限定边界）；点楼栋→推镜进 S2。

**构图与落位**（竖屏 750×1624；地块坐标取 `config/map_def.json`，等距网格）：

| 分层 | 内容 | 落位/数量 | 表现要点 |
|---|---|---|---|
| 远景 | 天空/天气 | 全屏 | 昼夜+天气氛围（见 §五矩阵） |
| 中景-北 | **主楼**（核心堡垒） | lot_bld_a (2,3) | 6 层×5 房等距大体量、金色窗光；B/C 栋 (5,3)/(6,5) 为 D30 锁定预载位 |
| 中景-南 | **30 栋独栋小屋群落** | 3 列×10 行错排，spacing≈1.2 格 | 每栋 6 级进化外观；住户在场→烟囱冒烟（呼吸节奏）；夜间窗光比例=存活住户映射 |
| 中景-公建带 | 八件套 | 道路两侧（食堂/仓库/医务/工坊/广播/议事/岗哨塔） | 每座 3 级外观（lv1 基础/lv2+构件/lv3 全装）；岗哨塔含情报范围光圈动效 |
| 防线 | 大门+围墙 | lot_gate (3,7)、lot_wall (2,6) | 模块化段（直段/转角/大门），可破坏三档状态；血月夜围墙外缘红光呼吸 |
| 点缀 | 中央广场 | (4,5) | 公告板/集市/事件触发地场景位 |
| 入口 | 出大门→L1 | 大门处 | 「出门探索」入口按钮（体力/队伍） |
| UI 叠加 | HUD+资源栏+dock 四键（布防/招募/升级/▶夜） | 顶部/底部 | 热区 ≥88px；探索队状态常驻角标；天气角标 |

**状态变体**：昼夜（窗灯/光照）、6 天气、血月（全场红移+vignette）、B/C 栋锁定态（D30 前）。

**验收**：等距楼栋可点、公建面板可达、大门可进 L1；夜窗比例正确；同屏 DC ≤60。

### S2　L3 房屋内部（室内层）

**镜头**：类 3D 室内剖面（单房放大，保留剖面传统：两面墙+地板）。

| 元素 | 规格 |
|---|---|
| 构图 | **门在右、窗在左**；窗=可见 L1 外景+天气的视口 |
| 家具 | 2–3 件按住户职业实体化：厨师→灶台、猎人→了望窗、守卫→武器架；通用件：床/桌/储物箱（单件 ≤4 个 box 组合，保留槽位锚点） |
| 工事位 | 门 barricade 槽、窗木板槽、室内武器架——对应 fort 槽位的可视化 |
| 住户状态机 | 健康（正常）/ 受伤（绷带叠加）/ 恐慌（抖动+冷汗）/ 睡觉 / 死亡（灰化+倒地 3 帧）/ 出逃（门位离场帧） |
| 事件 | 室内专属 `evt_in_*`（墙角异响/地板下发现/窗外来客） |
| 皮肤 | 3 主题换色+换件（M4 付费）：默认废土求生（冷蓝+原木）/ 温馨家园（暖黄+碎花）/ 赛博堡垒（霓虹青+金属）——同槽位不换布局 |

**验收**：工事槽位/住户状态/岗位指派可用；窗外可见 L1 天气。

### S3　L1 野外大地图（探索层）

**镜头**：类 3D 斜俯视（45° 等距，带高度与遮挡），夜雾/天气氛围叠层。

| 区域 | 内容 | 危险度 | 解锁 |
|---|---|---|---|
| 林缘 (1,1) | 浆果丛/野菜/蘑菇采集点 | 低 | D1 |
| 深林 (0,0) | 木材/草药/蜂蜜；猎物鹿/兔；危险野猪/狼 | 中 | D8 |
| 街道废墟 (6,0) | 建材/罐头/布料搜刮点；流浪幸存者遭遇 | 中（夜间怪物流窜） | D12 |
| 河边农田 (0,5) | 水/鱼/作物；钓鱼/取水点 | 低-中 | D5 |

**场景套件资产**：树×3（针叶/阔叶，三档尺寸）、灌木/浆果丛、蘑菇、岩石×2、废墟段×2、农田/河沿地块、营地（篝火+帐篷）；野物：鹿/兔/野猪/狼（3/4 侧行走循环，prey 体型弱化）；采集图标 8 枚（浆果/野菜/蘑菇/木材/草药/蜂蜜/鱼/水）。

**动态**：野外专属事件 `evt_wd_*`；夜晚遭遇率/危险野物大增（视觉危险度区分）；滞留队伍营地阶段（篝火+防御）。

**验收**：四区域可达、派出/归来结算可视、夜晚危险度有视觉区分。

### S4　夜战攻防演出（NIGHT 全屏）

**分层深度模型**（非平面，类 3D 关键）：

| 层 | 内容 | 表现 |
|---|---|---|
| 远景 | 夜空/月亮/血月/星点/天气 | 全屏；血月红雾+红移 vignette |
| 中景（战场） | **3 条深度车道**（远/中/近），尺寸缩放 0.8/0.9/1.0 | 怪物沿车道行进；一切地面实体带椭圆投影 |
| 近景（防区） | 每车道右端=目标小屋立面（按房屋等级外观）+守卫住户 | 小屋可受击/破损（茅草屋掉草、石屋冒尘） |
| 顶部 HUD | 波次进度条+技能按钮（CD 环，热区 88px） | 常驻 |

**双方状态机动画**：
- 怪物：`spawn(边缘淡入)→advance(行进 bob)→attack(扑击循环 0.4s)⇄hitFlash(白闪2帧+击退6px)→die(崩解粒子+倒地淡出)`；破防=小屋血红脉冲。
- 守卫：`guard(呼吸站岗)→block(格挡火花)→counter(反击突进)→wounded(倒地红闪)→heal(回位)`。
- 高度线索：飞行种悬浮（影子与本体分离）；精英跃起抛物线；体型 1.3×+红眼。
- 节拍：每波 3s（行进 1.2→交战 1.2→结果 0.6），演出总长=波数×3s，支持 2× 速/跳过。

**技能 VFX**：空投=降落伞摆动下落 1.2s→落地光圈→物资箱弹开+光柱；护盾=蓝色半球罩（六边纹呼吸）受击弹火花；主角技=扇形冲击波+地面裂纹；血月尘暴=红沙横风+能见度罩。

**特殊夜**：血月（全区进攻+红光）、静默夜（无预告，怪物半透明 70%+红眼）、迁移夜（怪物拖影换目标）。

### S5　收租结算·物资雨（DAWN 标志性瞬间）

- 金色物资箱/方块 24 粒子从主楼顶落下（rain 曲线 500ms+动态拖尾）→ 金币计数器滚动（0.8s）。

## 七、生产管线与验收门（怎么交稿）

**流程**（AI 生图与人工绘制同一套门）：
1. 生成：每资产 8 候选，附锚点参考图（一致性）；≥3 轮带病因重试。
2. 挑选：抠底→色板吸附→覆盖率窗口+色彩层次+**色板命中率权重**评分取最优。
3. 校验四门（`node scripts/check-assets.mjs`）：① 色板（UI ±10% 硬门 / AI 扩展色板 ≥85%）② 72px 剪影可读（`char` 类）③ 深色描边一致 ④ 透明底+覆盖率窗口（全出血类豁免）；fx 贴图走软边门。**人眼层补查**：AI 乱码文字/色卡图例/多余肢体（程序门测不出）。
4. 入库：`docs/assets/ai/{模块}/`，命名 `{模块}_{对象}_{状态}@2x.png`；`node scripts/sync-sprites.mjs`（或 `npm run build:whitebox` 一并打包）同步运行时 → `apps/client-cocos/whitebox/assets/ai/`，引擎按清单加载（缺资产自动回退程序化绘制，不阻塞）。
5. 复跑门禁：`check:assets` + `check:theme` + `check:config` + `check:size` + E2E（20/20）；视觉验证画廊 `?spritedbg=1`。

**批量生产命令**（账户就绪后）：

```bash
npm run gen:assets:ai -- --dry                              # 无 key 试跑
npm run gen:assets:ai -- --only houses,monsters,weather,vfx,fx   # P2-2 批量续跑（预估 ≤¥60）
```

提示词修订通道：`docs/assets/ai/prompt-overrides.json`（重跑生效）；轮次/病因证据：`docs/assets/ai/ai-report.json`。
