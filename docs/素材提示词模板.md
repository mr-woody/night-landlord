# 素材提示词模板（M3 素材期启动件，v1.1；v1.1=§0 分视角后缀表，M5 等距 2.5D 升级）

> 定位：AI 生图账号就绪后的**即用提示词库**——全部提示词按《2D美术资产规范》§十五 统一后缀拼装，
> 资产清单对齐美术规范 §十四 与本项目已实现的实体（monster.json id / 房屋 6 级 / 天气 6 型）。
> 用法：任选生图工具（即梦/Midjourney/SD+LoRA 均可），每资产生成 8 候选 → 按 §16 校验清单人工挑选 →
> 入库走 `check-assets.mjs`（色板 ±10%/72px 剪影/描边/透明底/命名四门）→ 以同名替换程序化占位。

## 0. 通用模板（统一基础后缀 + 分视角后缀，M5 §3 视角规格）

**基础后缀**（所有视觉资产统一）：

```
{主体描述}, {视角后缀,下表五选一}, 末日生存卡通风格, flat shading, 粗深色描边(轮廓线宽度≈线幅8%), 高饱和点缀,
左上光源, 透明背景, 竖版手游素材, 3–4 色块面, --ar {比例}
```

**分视角后缀**（2.5D 立体性核心，同屏实体必须同视角）：

| 视角档 | 后缀 | 适用 |
|---|---|---|
| 等距 iso | `等距 2.5D 视角, 俯角约 30°, 方位角 45°(左上前), 统一消失点, 带接地投影` | 主楼/小屋/公共建筑/等距场景 |
| 侧面 side | `3/4 侧面视角, 面朝画面右(行进方向), 带接地椭圆影` | 怪物/住户战斗实体 |
| 正面 front | `正面半身, 平视, 圆框头像构图` | 住户头像/图鉴立绘 |
| 图标 icon | `正视, 居中单体` | 图标/UI/VFX 单体 |
| 全景 flat | `正视全景构图` | 天气氛围/全屏定格帧 |

**负向**：`写实, 3D 渲染, 渐变背景, 文字, 水印, 多光源, 复杂细节`

**色板锚定**（主色必须落位，±10%）：`#0B1020 描边 / #FFD700 金 / #C0392B 血红 / #7FFF9F 成功 / #8892B0 灰 / #1A2238 面板`

## 5. 流程（对齐美术规范 §十五）

1. 每资产 8 候选 → 人工挑 1（附锚点图作参考图，一致性策略）
2. 清理：抠底/统一光源/裁边
3. 校验：`node scripts/check-assets.mjs`（§十六 四门）
4. 集成：同名替换 `apps/client-cocos/whitebox` 占位 或 Creator assets，图集走 TexturePacker

> 命名红线：`{模块}_{对象}_{状态}@2x.png`；主色偏离色板 ±10% 直接打回。

## 6. AI 接入管线（M3 起效，agent 闭环）

`scripts/gen-ai-assets.mjs` 将 §1–4 清单接为「生成→校验→带病因重试」自动闭环，生图账号=火山方舟 Seedream（即梦同源，API 见 `.env.example`）：

```
npm run gen:assets:ai -- --dry          # 无 key 试跑（mock 出图，验证闭环）
npm run gen:assets:ai -- --only anchors # 真跑某模块（key 在 .env）
```

- 四门校验按 §十六 视觉段参数化复刻（色板吸附后 ≥98% 命中、72px 剪影、深色描边、透明底+覆盖率窗口），不过关自动带病因重生成（≤`--rounds` 轮）
- agent 迭代通道：`docs/assets/ai/prompt-overrides.json`（修订提示词，重跑生效）+ `docs/assets/ai/ai-report.json`（每资产轮次/病因/终态证据）
- 产出：`docs/assets/ai/{anchors,houses,monsters,weather,vfx}/`，候选证据在 `candidates/`（不入库）；终图人工/agent 确认后同名替换 §5 流程入库
