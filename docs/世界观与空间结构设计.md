> 定位：本档是「小区 + 野外大地图 + 可进入房屋内部」新空间设定的**唯一权威定义**，是需求文档、配置表、UI/UX、美术各 v2/v3 修订的上位输入。
> 修订来源：2026-08-30 用户方向决议——单楼剖面升级为「小区多栋房屋 + 可进入房间内部 + 外部夜晚/森林野外（野物/野草/野果/意外事件）」，UI 升级为类 3D 空间视觉。
> 不变式（红线）：核心日循环（收租→经营→入夜→夜战→结算）、M0 数值契约（V0–V12 硬门）、`applyEffects` 单点（D4）、插件化架构（FR 全系）**全部保持**。本档只扩展"空间与探索层"，不改收益逻辑。

## 1. 世界结构：三层空间模型

```
┌─────────────────────────────────────────────┐
│ L1 大区域地图（野外层）                        │
│   小区围墙外：森林/街道废墟/农田/河流           │
│   野物 · 野草野果采集点 · 意外事件 · 昼夜光照    │
├─────────────────────────────────────────────┤
│ L2 小区地图（家园层）                          │
│   3–5 栋住宅楼 + 大门围墙 + 八件套公共建筑       │
│   楼间道路 / 广场 / 瞭望塔（小区级防线）         │
├─────────────────────────────────────────────┤
│ L3 房屋内部（室内层）                          │
│   可进入的单个房屋内部：门/窗/家具/住户活动       │
│   工事布置点 · 住户岗位 · 房屋级事件             │
└─────────────────────────────────────────────┘
```

| 层 | 玩家主要行为 | 视角 | 打开方式 |
|---|---|---|---|
| L1 野外 | 外出探索/采集/狩猎/遭遇事件 | 类 3D 斜俯视（45° 等距，带高度与遮挡） | 小区大门出发，消耗体力与时间窗 |
| L2 小区 | 布防/建造/公共建筑/收租结算 | 类 3D 斜俯视（楼栋可点击） | 默认主界面 |
| L3 室内 | 看住户状态/布置工事/房间事件 | 类 3D 室内剖面（单房放大，保留剖面传统） | 点击楼栋→点击房间 |

**与既有设定的衔接**：设计方案 §4.1 的扩张路径「单间→一层→一栋→小区→街区」中，"小区"原为终盘内容，现提前为**开局即是的家园形态**；"一栋楼内部"由 L3 室内层承载（保留辐射避难所式剖面的遗产，但以真实房屋内部呈现，不再把 6 层画在一张图里）。

## 2. L2 小区地图（家园层）

### 2.1 地块构成（首版 3 栋，可扩至 5 栋）

| 地块 | 数量 | 说明 |
|---|---|---|
| 住宅楼 A/B/C | 3（赛季扩至 5） | 每栋 6 层×5 房（沿用 30 户/栋锚点）；A 栋开局解锁，B 栋 D30 解锁（对齐 M0「D30 第 2 栋」锚点） |
| 大门 & 围墙 | 1 | 小区总防线（既有 gate/wall 建筑落位）；被破则夜战威胁加成（沿用既有设定） |
| 公共建筑带 | 8 件套 | 食堂/仓库/医务室/工坊/广播站/议事厅/岗哨塔（既有定义不变，落位小区地面道路两侧） |
| 广场 | 1 | 事件触发地/公告板/集市场景位 |
| 出入口 | 1 | 连接 L1 野外的唯一通道（大门） |

### 2.2 楼栋与房间

- 每栋楼保留"层×房间"结构作为**数据模型**（30 户/栋锚点不变），但表现层不再是整栋剖面图：点击楼栋 → 该栋的层选择 → 进入 L3 房间内部。
- 夜战防守单元仍是"房间"（多路分散防守的核心谜题不变）；夜战面板新增**房间所在楼栋**维度（预告"今晚袭击 A 栋 3 层 2 号房"）。

## 3. L3 房屋内部（室内层，新系统）

### 3.1 房屋内部视图

- 单间房屋的类 3D 内部：地板/两面墙（保留剖面朝向）、门（右侧，既有设定）、窗（左侧，可见 L1 外景）、家具 2–3 件（按住户职业：厨师→灶台、猎人了望窗、守卫→武器架）。
- 家具=**工事与生产位**的实体化：门 barricade 槽、窗木板槽、室内武器架（对应既有 fort 槽位概念，可视化）。
- 住户在室内实时呈现状态机（健康/受伤绷带/恐慌发抖/睡觉），点击住户 → 住户详情（既有五维面板）。

### 3.2 室内交互

| 交互 | 内容 | 数据来源 |
|---|---|---|
| 工事布置 | 门/窗/家具位安装 barricade、武器架 | building_def.fort 槽位（既有） |
| 岗位指派 | 守夜/生产岗位可视化摆放 | 住户岗位（既有 systems） |
| 房间事件 | 室内专属事件（墙角异响/地板下发现/窗外来客） | event_lib 新增 `evt_in_*` 组 |
| 装修皮肤 | M4 外观付费（既有 §5.2 三主题），本档只预留槽位 | 房间皮肤主题（既有） |

## 4. L1 野外大地图（探索层，新系统）

### 4.1 地图构成

| 区域 | 内容 | 危险度 |
|---|---|---|
| 林缘 | 浆果丛/野菜/蘑菇（基础食物采集点） | 低（白日安全） |
| 深林 | 木材/草药/蜂蜜；野物：鹿/野兔（猎物），野猪/狼（危险野物） | 中 |
| 街道废墟 | 建材/罐头/布料（搜刮点），流浪幸存者遭遇（事件） | 中（夜间怪物流窜） |
| 农田/河边 | 水/鱼/作物残存；钓鱼/取水点 | 低-中 |
| 随机意外 | 蜂群、捕兽陷阱、塌方、雾夜迷路、深夜敲门（野外版） | 事件库驱动 |

### 4.2 探索规则（新增系统：explore 插件）

- **体力与时间窗**：外出消耗住户体力与当日时间；每次外出选定"队伍（1–3 名住户）+ 目的地"；目的地距离决定耗时（可能跨过入夜点→夜晚滞留野外的风险决策）。
- **采集**：采集点按资源表刷新（野果/野草/木材…），产出走 EffectOp 入六资源体系（不新增资源种类）。
- **狩猎与野物**：猎物（鹿/兔）=食物产出（猎人职业加成）；危险野物（野猪/狼）=野外战斗（轻量回合制，弹药消耗，战败=住户受伤/物资损失）。
- **意外事件**：野外专属事件组 `evt_wd_*`（沿用事件库 schema：文案+选项+EffectOp 后果），examples：狼群夜袭营地/发现猎户小屋/迷路的孩子（救援→引荐住户，对齐"邻里引荐"设定）。
- **夜晚野外**：入夜后野外遭遇率与危险野物出没大增（与小区夜战同一时间轴）；滞留队伍需"营地防御"或提前返回。

### 4.3 与核心循环的咬合（关键：不加塞、不破坏既有节奏）

```
白天经营（既有）＋ [新增可选] 派队外出（消耗时间/体力，产出在下次结算时带回）
夜晚小区夜战（既有，不变）＋ 野外滞留队伍的营地阶段（简短）
天亮结算（既有）＋ 外出队归来结算
```
- 数值红线：野外产出**计入 M0 六资源产出的再分配**，不改 income/rent 主曲线；`day_curve` 主表不动，新增 `explore_def`/`gather_table` 独立平衡（见 §8 配置冲击）。
- 体力/时间消耗走 constants 新增键（`EXPLORE_*` 命名段，走 constants 安全区间机制）。

## 5. 视觉方向：类 3D（2.5D）场景规范

| 项 | 定值 |
|---|---|
| 投影 | 斜 45° 等距（2.5D isometric），物体带高度（楼栋 6 层体积、树木、围墙高度差） |
| 镜头 | L1/L2 支持双指缩放与平移（限定边界）；点击建筑→推镜进入 L3 室内 |
| 光照 | 全局昼夜光照：白天暖金、黄昏橙红、夜晚深蓝+月光/血月红；建筑窗户夜间点灯（住户数映射亮窗比例） |
| 大气 | 夜雾（野外）、血月红雾、季节变体预留 |
| 建模 | 程序化 2.5D 组合体（box 堆叠+斜面屋顶+描边），对齐美术规范 v2 的 Flat shading+粗描边；M3 换 AI 素材时以同构图替换 |
| 性能 | 微信小游戏：可见区剔除+静态合批；同屏绘制调用预算 ≤60（白盒期实测） |

## 6. 系统与插件清单（对齐插件化架构）

| 新插件 | 职责 | 热插拔分级 |
|---|---|---|
| `rn.worldmap` | 三层空间状态（楼栋/房间/地块/采集点）与寻路/视口数据 | standard |
| `rn.explore` | 外出队伍、体力/时间窗、采集/狩猎/野外事件产出 | standard（可停=无野外玩法） |
| `rn.interior` | 房屋内部状态（工事位/家具/住户呈现投影） | standard |
| `rn.wildlife` | 野物生态（出没表/战斗） | removable |

- 全部走 FR-F1 闭环七槽位验收；状态变更一律 EffectOp（D4）；确定性：野外遭遇用 `createDayRng(seed,'explore',day)` 日域流，禁 Math.random。
