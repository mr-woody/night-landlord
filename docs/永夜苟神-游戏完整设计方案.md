# 《永夜苟神》游戏完整设计方案（纸面方案 v0.1）

> 依据：短剧《永夜苟神：十万住户供我发育》（改编自起点小说《我在永夜打造庇护所》）
> 目标：把剧集钩子映射到经过市场验证的经典/爆款游戏策略，输出从头到尾的完整玩法与商业设计。
> 状态：**仅设计，不含代码实现**。数值均为首版示意，供纸面原型调参用。
> **勘误（2026-08-29，M0 阶段）**：本文 4.5 的怪物强度公式 `(1+0.18d)^1.35` 与"第 30 天跳变"已被《[M0-数值模型-三曲线调参表](M0-数值模型-三曲线调参表.md)》§9 修正（恒定 1.15/天指数化、跳变日 7/14/21/28）；4.7 数值锚点已由 M0 档逐条展开并验收。冲突处以 M0 档为准。

## 一、策略推导：剧集钩子 → 经典/爆款游戏策略对标

先把剧集里"好玩的原子"拆出来，逐一对标已验证的游戏策略：

| # | 剧集钩子 | 对标的经典/爆款策略 | 代表游戏 | 可复用的已验证结论 |
|---|---|---|---|---|
| 1 | 永夜降临、夜晚怪物来袭 | 日夜循环压力结构：白天安全发育、夜晚风险爆发 | 饥荒 Don't Starve / Minecraft 第一夜 | "夜晚=死亡焦虑"是最普适的生存压力发生器 |
| 2 | 住户存活→每日爆物资 | **人是资产也是责任**：人口=收益引擎+保护义务 | 无尽冬日 Whiteout Survival / 辐射避难所 / 冰汽时代 | 幸存者经营的付费深度和情感黏性已被重度验证 |
| 3 | "苟神"人设：不打杀、只发育 | 放置/挂机的低操作高收益爽感 | 寻道大千 / 咸鱼之王 / AFK Arena | 下沉市场核心爽点：复利可见、躺着变强 |
| 4 | 天赋抽取、开局随机 | Roguelite build 多样性 + 抽卡商业化 | 吸血鬼幸存者 / 哈迪斯 / 弹壳特攻队 | 每局变奏防重复疲劳；天赋池天然承载付费深度 |
| 5 | 邻里矛盾、凝聚幸存者 | 社会生存叙事 + 道德抉择事件 | 这是我的战争 / 冰汽时代 | 抉择事件是低成本高传播的叙事引擎 |
| 6 | 房间加固、升级居所 | 基地建设 + 波次塔防 | 亿万僵尸 / 王国保卫战 / 保卫萝卜 / PvZ | "白天修墙晚上守"是久经考验的双相循环 |
| 7 | 怪物不断进化 | 波次难度曲线 + 章节Boss + 赛季变种 | PvZ 生存模式 / 亿万僵尸 / 无尽冬日赛季 | 强度跳变日=天然的内容高潮与付费卡点 |
| 8 | 剖面楼栋、竖屏观看习惯 | 竖屏剖面房间经营 | 辐射避难所 Fallout Shelter | 竖屏剖面图=小游戏最佳载体，直观且开发可控 |

**爆款公式套用**（为什么这个组合成立）：

- **公式 A（Last War: Survival / 无尽冬日）**：轻玩法前端（买量友好）+ 中度经营中台（养成深度）+ 社交SLG后端（长线留存在最后一层）。本方案首发做前两层，第三层作为 Phase 2。
- **公式 B（弹壳特攻队 / 寻道大千）**：核心循环 30 秒内可被买量素材讲清楚，IAA 广告位密织，IAP 承载深度。
- **公式 C（辐射避难所）**：竖屏剖面 + 人口收集 + 房间扩建，小游戏载体的祖师爷结构。

**差异化护城河（本作唯一的"人无我有"）**：
> 市面上所有末日生存游戏的收益逻辑是"抢夺/独活"，本作收益逻辑反转为**"护邻居而富"**——保人=赚钱，利他=自利。
> 这既是玩法谜题的来源（人口越多收入越高，但保护面越大），也是买量素材的戏剧冲突（"别人在抢罐头，我在给邻居发工资"）。

## 三、核心循环设计

**游戏内一天 = 现实约 4 分钟**（白天经营 2.5 分钟 + 夜晚防守 1.5 分钟），与小游戏碎片化时长匹配。

### 3.1 单日循环（分钟级，核心中的核心）

```
【天亮】收租结算 —— 物资雨动画，昨日存活住户逐户爆物资（爽点释放）
   ↓
【白天】四类经营决策（玩家自主排序）：
   ① 招募/救援：开门抉择、广播站招募、救援任务
   ② 建造/加固：升级房门、窗户、围墙、公共建筑
   ③ 分配：住户上岗（守卫/生产）、武器分发、陷阱布置
   ④ 事件抉择：每日事件（邻里纠纷、敲门人、物资发现……）
   ↓
【入夜预告】今晚攻击目标揭示：哪几个房间、怪物构成（信息即策略）
   ↓
【夜晚】多路攻防：自动战斗（塔防式）+ 玩家技能干预
   ↓
【天亮】结算：存活名单 → 收租 → 回到循环开头
```

### 3.2 多层循环嵌套

| 层级 | 周期 | 内容 |
|---|---|---|
| 秒级 | 1–5 秒 | 收益跳动、自动战斗反馈（放置爽感） |
| 分钟级 | 4 分钟 | 一天循环（上表） |
| 小时级 | 0.5–2 小时 | 楼层/楼栋解锁、住户养成、天赋局内构建成型 |
| 日级（现实） | 每日 | 日常任务、离线收益领取、限时活动 |
| 周期级 | 7 天 | 章节小高潮（血月/小Boss），对齐"一周"留存考核 |
| 赛季级 | 6 周 | 夜王 Boss、新区域扩张、新怪物变种、苟神榜结算 |

## 四、系统细节设计

### 4.1 空间结构（辐射避难所式竖屏剖面）

扩张路径：**单间(10㎡) → 一层(4–6间) → 一栋(6层) → 小区(3–5栋) → 街区(赛季扩张)**

- 每个房间 = 1 个住户槽位 + 若干防御工事位（门/窗/ barricade）。
- 公共建筑（楼层/小区级）：
  - **大门 & 围墙**：小区总防线，被破则夜晚威胁等级提升
  - **岗哨塔 / 瞭望塔**：提前揭示攻击目标数量（情报）
  - **广播站**：批量招募住户（解锁后招募效率质变）
  - **仓库**：资源容量上限（扩容是第一个软付费卡点）
  - **食堂**：食物承载人口上限
  - **医务室**：受伤住户治疗
  - **议事厅**：发布"公约"（秩序系统入口）+ 主线任务
  - **工坊**：武器/陷阱制造

### 4.2 住户系统（核心创新，全案重心）

**住户五维**：职业（产出/战斗/功能）、品质（N/R/SR/SSR）、状态（健康/受伤/恐慌/挨饿/死亡）、士气、特长。

**收益逻辑（保人=赚钱）**：
- 每个存活住户每日产出"生存点"（硬通货），不同职业产出不同资源：
  - 厨师→食物、工程师→建材提速、护土→治疗效率、猎人→弹药、职业人→金币
- **死亡代价设计（关键）**：住户死亡不是扣减存量资源，而是**永久断掉这条收入线**。
  - 心理学依据：损失厌恶 + "断财路"比"扣存款"痛苦更持久、报复动机更强（第二天更想加强防御/花钱）。
  - 文案包装："怪物吃掉的不是你的人，是你的钱。"

**恐慌与秩序（冰汽时代式）**：
- 夜晚破房、挨饿、邻里纠纷 → 住户恐慌值上升。
- 恐慌住户的行为风险：夜间开门引怪、偷仓库、次日出逃（收入线流失）。
- 议事厅可发布"公约"压制恐慌：宵禁、配给制、连坐……每条公约=一次道德抉择，提升秩序但降低士气/产出系数。

**招募渠道**：
- 白天敲门事件（"开不开门？"——这是我的战争式抉择：开门=可能招到人才/放入卧底怪物；拒之门外=安全但损失口碑）
- 广播站批量招募（消耗物资+口碑）
- 救援任务（夜里被围的住户，白天去救，高风险高回报）
- 邻居介绍（存活住户的社交连锁，N 住户 3 天后引荐新住户——把"保人"的收益再滚一层）

**关键角色卡（IP 直接植入）**：
- **江莱**（SSR·理财）：租金复利+，商店折扣
- **林鹿溪**（SSR·战斗）：守夜战力质变，可主动出击救援
- 后续赛季上新剧内角色，与短剧更新节奏联动。

### 4.3 天赋系统（roguelite 变奏 + 商业化双轮）

- **局外天赋树**（永久养成，付费深度所在）：三条分支对应三种 build 流派——
  - 收租流（利率/租金加成）、铁壁流（工事/减伤）、人口流（招募成本/人口上限）
- **局内天赋抽取**（每 3 天三选一，roguelite 变奏）：防止每日循环同质化。
- 天赋示例（直接取材剧集）：

| 天赋 | 品质 | 效果 | 流派 |
|---|---|---|---|
| 收租宗师 | SR | 每日租金 +25% | 收租 |
| 夜猫子 | R | 夜晚视野+1，可预览 1 个隐藏攻击点 | 铁壁 |
| 铁公鸡 | R | 全消耗 -10% | 万金油 |
| 人缘爆棚 | SR | 招募成本 -30%，引荐周期减半 | 人口 |
| 邻里和睦 | SR | 恐慌获取 -50% | 秩序 |
| 唯我独尊 | SSR | 全资源 +15%，每夜 1 次免费空投 | 全能（剧内主角天赋） |

### 4.4 战斗系统（分散防守=核心谜题）

与单线塔防的本质区别：**每个夜晚，怪物进攻 N 个住户房间（多路、分散），玩家防御资源永远不够护住所有点。**

- **入夜前信息**：预告今晚被攻击的房间与怪物构成（瞭望塔等级提升情报精度）。
- **白天布防**：把有限的防御点数分配到预测目标——护 A 就漏 B，这是每日的主策略谜题。
- **岗位与武器**：战斗住户安到岗哨/房间守夜；武器有耐久、弹药有消耗（战斗成本）。
- **夜晚操作**：自动战斗为底，玩家手动释放主动技（空投物资、临时工事、主角技能）作为干预——对标弹壳特攻队"自动为主+技能为爽"。
- **失败不 Game Over（苟神不死原则）**：
  - 破防房间 → 住户受伤/死亡（收入线受损）；
  - 主角房间永不被灭，保住"下一天还能翻盘"的最低保障。
  - 依据：苟系用户厌恶全损重来，损失要"疼但不死"。

### 4.5 怪物系统（进化=内容节奏器）

进化树（对齐短剧"不断进化的魔物"）：
循声者（杂鱼）→ 破窗者 → 攀楼种（翻窗）→ 飞行种（无视楼层）→ 围攻AI（集火弱点）→ 精英种 → 章节Boss **夜王**。

- 强度示意公式：`怪物HP = base × (1 + 0.18 × 天数)^1.35`，第 7/14/21/30 天跳变（跳变日=血月/高潮日=付费与传播卡点）。
- 特殊夜机制（防循环疲劳）：
  - **血月夜**：全区进攻，强度跳变
  - **静默夜**：无预告偷袭（考验冗余布防）
  - **迁移夜**：怪物临时更换目标（打乱既有布防，考验临场技能干预）

### 4.6 资源与经济（复利飞轮 + 防失控黑洞）

- 六种资源：食物、水、建材、弹药、**金币（收租硬通货）**、天赋石。
- 飞轮：住户→产出→再投资（加固/招人/武器）→更多存活住户→更多产出。
- 防滚雪球黑洞：建筑升级线、武器耐久、**人口受食物承载力约束**（食堂等级=人口上限，逼迫玩家在"贪人口"与"先升级食堂"间做取舍）。

### 4.7 数值框架（首版示意锚点）

| 锚点 | 目标 |
|---|---|
| D1 结束 | 10 住户，日租金可覆盖 2 项基础升级 |
| 第 7 夜（血月） | 玩家战力恰好卡在"勉强能过/需要补强"区间（软付费墙） |
| D30 | 第 1 栋满层，解锁第 2 栋，赛季 Boss 预告 |
| 产出曲线 | 指数≈1.12/天；强度曲线指数≈1.15/天（强度略压产出，制造稀缺） |
| 广告收益基准 | 每DAU日均 4–6 次激励视频（对标寻道大千密度） |

### 4.8 事件系统（短剧化叙事引擎）

每日 1–2 个事件，事件 = 文案 + 2–3 选项 + 后果（资源/住户/秩序波动）。

| 示例事件 | 选项 | 设计意图 |
|---|---|---|
| 深夜敲门人 | 开门 / 隔门询问 / 无视 | 道德抉择 + 风险收益（可能招到SSR/放入怪） |
| 邻居偷粮 | 公审 / 私了 / 放任 | 秩序系统教学 + 戏剧张力 |
| 阳台物资箱 | 独占 / 平分 / 换情报 | 口碑值体系引入 |
| 7 楼老太被困 | 派人救 / 遥控指挥 / 放弃 | 救援玩法钩子（复刻剧内名场面） |
| 短剧名场面复刻 | — | IP 联动素材，赛季随剧更新 |

### 5.1 IAA 广告位（对标寻道大千/弹壳密度）

| 广告点 | 效果 | 频控 |

| 商品 | 定位 | 对标 |
|---|---|---|
| 月卡/基金 | 永久租金 +% | 行业标准 |
| 永夜战令（双轨） | 赛季内容付费主线 | 无尽冬日 |

| 资源礼包 | 卡点破冰：第 7 夜血月前 | 全行业 |

### 5.3 破冰与买量

- 破冰节奏：D3 扩容软卡点（仓库/食堂扩容）→ D7 血月（付费最优时点）→ D14 赛季 Boss。
- 首充：SSR 林鹿溪 + 7 天租金 ×2。
- **买量策略（Last War 公式：素材即玩法）**：核心循环 30 秒可讲清，天然 playable ad。三条首发素材脚本：
  1. 收租名场面（天亮物资雨，"十万住户供我发育"）
  2. 开门抉择（"门外是人才还是怪物？"）
  3. 血月守楼（护邻居 = 护钱袋子）

## 七、长线运营

- **赛季制 = 剧季制**（6 周一季）：新怪物变种 + 新区域 + 新天赋池；赛季内容节奏对齐短剧更新，剧更一季、游戏更一季，角色卡随剧上新。
- **苟神榜**：存活率 × 资产综合排名（强化"苟"的荣耀感，而非战力榜）。
- 联盟/社交（Phase 2，无尽冬日路线）：小区联盟、互助协防（你帮我守夜）、资源市场、联盟赛季 Boss——SLG 化后端承载长线留存与社交付费。
- 活动日历：周末血月双倍、节日限定皮肤、剧更联动事件。

## 八、美术与音频方向

- **竖屏剖面动态漫风格**：对齐短剧 AI 漫剧审美（买量素材一致性好，美术成本低）。
- 色彩情绪：夜晚冷色压迫（深蓝/血红警示）vs 白天暖色收租（金色物资雨）。
- **标志性瞬间（Signature Moment）**：天亮收租"物资雨"逐户爆钱动画——所有买量素材围绕它生产。
- 音频：夜晚低频压迫音 + 天亮收租的清脆金币声（条件反射式爽感锚点）。

## 九、风险、假设与验证计划

### 核心假设（按优先级）

| # | 假设 | 验证方法 | 判定标准 |
