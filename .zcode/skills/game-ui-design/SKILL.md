# Game UI Design（night-landlord 项目技能）

## 何时使用
- 用户要求设计/修改任何游戏界面（主界面、事件卡、夜战、收租、天赋、商店、图鉴）
- 用户要求动效规范、交互流、UI 风格化或游戏资产生成

## 强制上下文（先读后动）
1. `docs/UI-UX设计规范.md` —— 设计原则与 Design Tokens 是合同，禁止发明规范外的色值/字号/曲线
2. `config/theme.json`（存在后）—— tokens 单一事实源
3. `docs/可执行目标-M2.md` §功能点6 —— 白盒渲染器布局原型
4. `docs/M0-事件文案库50条.md` —— 事件文案语调基准
5. `docs/2D美术资产规范.md` —— 游戏**内**美术资产（人物/房间/怪物/物品/环境）规格与 AI 生成模板；UI 素材仅限本文档 §五 管线

## 工作流
1. **定位模块**：确认目标界面属于哪个模块（§3.1–3.5 模板之一或新模块）
2. **套模板产出设计稿**：ASCII 线框（竖屏 750×1624）+ 交互流（触发→反馈→闭环）+ 动效标注（曲线/时长从 theme.motion 取）
3. **红线校验**（逐条过）：
   - 色值全部来自 theme.color，不得新增 hex
   - 热区 ≥88×88px；正文字号 ≥24
   - 每个交互 ≤0.1s 有响应；爽点动效 ≥0.5s
   - 双相色彩：白天暖/夜晚冷，切换必带 800ms dissolve
   - 事件效果算子仅限 EffectOp 词表（applyEffects 单点，D4）
4. **资产需求**：按 §五 prompt 模板产出 AI 生成指令 + 校验清单
5. **产出物**：设计稿追加到 docs/UI-UX设计规范.md 对应章节（或新章节），实施项进对应里程碑目标文档

## 禁止
- 引入规范外语色/字号/动效曲线
- 跳过红线校验直接产出
- 把效果算子写到 applyEffects 词表之外（D4 单点铁律）
- 在夜战面板加可打断交互（全屏接管铁律）
